# CUT&Tag 分析流程搭建与实践指南

面向希望自行搭建 bulk 双端 CUT&Tag 分析流程的使用者，以及协助部署、分析和排故的 AI。内容来自一套已完成本机环境建设、真实人源数据分析、报告生成和故障处理的工作台实践。

本目录可以单独下载或作为 GitHub 文档仓库发布。阅读不依赖作者的其他目录、聊天记录、私有脚本或原始数据。

## 从这里开始

1. 阅读 [完整指南](GUIDE.zh-CN.md)，确认适用范围和本机验证边界。
2. 将 [AI 执行入口](AI_START_HERE.md) 与整个目录交给具备文件、终端和网络访问能力的 AI。
3. 复制 [空白样本表](templates/samples.tsv)，参考 [虚构填写示例](templates/samples.example.tsv) 和 [参数示例](templates/parameters.example.yaml) 整理真实实验信息。
4. 用 [部署与运行记录](templates/RUN_RECORD.md) 和 [验收清单](templates/ACCEPTANCE.md) 记录本机实际执行情况。
5. 查阅 [官方资料索引](SOURCES.md) 和 [文档变更记录](CHANGELOG.md)。

## 能获得什么

- 安装与环境隔离、参考准备、输入预检、QC、比对和成对过滤的路线。
- 同库加测、重复标记、spike-in、峰、轨道、TSS、注释与富集的关键口径。
- 报告与完整附件的设计要求、结果核对、失败恢复、归档与维护经验。
- AI 实施时的阶段任务、必须验证的边界，以及不能靠默认值补齐的实验信息。

## 已验证到哪里

| 层次 | 作者本机已有依据 | 使用者需要补做 |
|---|---|---|
| 部署 | Apple Silicon / macOS，分模块 Conda 环境 | 在自己的系统和架构安装、导出实际环境锁 |
| 科学分析 | 真实人源 bulk 双端 CUT&Tag 的基础分析、保存结果核对及报告 | 用自己的输入、参考、参数和实验设计验证 |
| 软件机制 | 合成数据和组件验证覆盖过同库加测、恢复、部分校准/重复性及报告边界 | 不把合成测试当成相应真实实验已通过 |
| 跨平台 | 提供 Linux、Intel Mac、Windows/WSL2 的适配方向 | 本公开版未在这些平台完成端到端部署验收 |

这是实践参考文档。正文给出通用工具命令、处理合同和实现任务；自定义成对处理、轨道统计、自动报告和恢复调度等内容，需要使用者或 AI 实现并测试。本目录未提供作者工作台的程序、GUI、环境、参考文件、数据或报告模板；正文的新组合示例也未作为独立公开流程重新跑通。

示例中的阈值是起点，指标一致性不等于实验合格，探索性峰关联也不等于基因表达或通路活性结论。
