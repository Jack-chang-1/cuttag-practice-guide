# 分阶段验收清单

逐项填写状态与证据，使用“通过 / 不通过 / 不适用 / 待确认”。本文件中的未勾选项都是要求，不能复制成成功记录。必需项不因期望“全绿”而被设成不适用。

## A. 范围、平台与部署

- [ ] A01：明确系统/架构、工作目录、权限、输入位置和期望模块。
- [ ] A02：内存/线程/临时文件/空间预算和长任务运行条件已核对。
- [ ] A03：安装器来源与官方校验匹配；环境按平台部署，无误装架构。
- [ ] A04：模块工具实际运行，Java 和 R/Bioconductor/数据库来源正确。
- [ ] A05：实际安装环境锁、工具版本和外部依赖记录已保存。

## B. 合成机制与代表性验证

- [ ] B01：预检覆盖损坏 gzip、配对 ID/数量/记录长度不一致并能明确失败。
- [ ] B02：11 对已知分类用例在保留/删除重复两种政策下闭合。
- [ ] B03：孤立 mate、同名多主记录、lane 名冲突、blacklist 边界正确处理。
- [ ] B04：短片段/dovetail、末 bin、全零范围和 bigWig 已知值实读核对。
- [ ] B05：FRiP 重叠多峰只计一次；零峰/零宿主分支有正确语义。
- [ ] B06：同库 RG/PU/LB 与联合重复标记符合真实文库关系。
- [ ] B07：TxDb 实际创建/重载；报告/表格边界和恢复机制按启用范围测试。
- [ ] B08：获准的代表性真实数据全链路验证单独登记，未以合成测试替代。

## C. 批次、输入与参考

- [ ] C01：样本表、来源行数/分析文库数、同库关系和独立重复有实验依据。
- [ ] C02：角色/靶标/组别/IgG 引用及未知项已核对。
- [ ] C03：原始文件完整预检、来源已有哈希和本机哈希一致。
- [ ] C04：FASTA/GTF/索引/区域/blacklist/TxDb/OrgDb 同版且已核验。
- [ ] C05：spike-in 检测、计数、校准资格分开；依据不足保持关闭校准。
- [ ] C06：参数、实现代码、依赖/参考身份与本运行冻结，检查点已审阅。

## D. 科学产物与数值

- [ ] D01：raw/clean pairs、reads、bases、修剪记账和量纲一致。
- [ ] D02：全部终止类别合计等于 clean pairs，独立诊断子集未重复相加。
- [ ] D03：宿主 BAM 主记录数为有效片段两倍，片段 BED 行数一致，BAM/BAI 有效。
- [ ] D04：轨道片段分母、参考范围、bin/单位/缩放与独立已知值一致。
- [ ] D05：峰/全量注释行数相等，稳定 ID 对应，Unannotated/坐标有明确去向。
- [ ] D06：FRiP 分子/分母与同分支宿主片段一致，且在合法范围。
- [ ] D07：GO/KEGG 目标/背景/映射/检验家族/数据库快照及完整表可核对。
- [ ] D08：可选 motif/相关性/PCA/排查按实际范围验证，跳过有原因。
- [ ] D09：FastQC/工具 warning、执行失败、实验限制和候选解释分别记录。

## E. 报告与完整包

- [ ] E01：本次报告身份/模块/限制正确，每个冻结版本有明确主入口。
- [ ] E02：完整表未被 Top 10 截断，搜索/末页/CSV 覆盖全部匹配行和原字段。
- [ ] E03：极小 P 值、基因名/ID、坐标和 Excel 字段类型实读核对。
- [ ] E04：原图、缩图、相对附件、BAM/BAI 和可选 IGV 依赖同行。
- [ ] E05：最终期望的 file/HTTP 模式、实际浏览器下载和会话打开分别验收。
- [ ] E06：整个包 SHA-256、所需文件与来源清单核对通过；新展示另建版本。

## F. 记录、归档与维护

- [ ] F01：命令/退出码/尝试/版本/参考/参数/代码/资源证据及原始失败完整保留。
- [ ] F02：续跑按指纹和输出身份复用，改变上游方法时明确下游重算。
- [ ] F03：归档副本按复制前已有哈希核对，未核验项如实登记。
- [ ] F04：需要恢复/诊断的中间文件保留；保护环境/参考与链接依赖。
- [ ] F05：如需清理，具体对象、归档证据、引用/活动检查和当次授权另行齐全。
- [ ] F06：交接包含运行入口、记录位置、待确认事项、实际验证范围和下一步。

## 记录方式

在自己的 RUN_RECORD 中按编号填写状态、证据路径、日期和说明。只有实现或语法检查的条目，不能填写为真实数据/现场操作通过；不适用要说明对应角色、模块或条件。
